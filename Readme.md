# HelloWorld

## Autor
Bryan Almonte

## Descripción
Proyecto desarrollado con React Native y TypeScript.

La aplicación muestra un mensaje de carga y permite cambiar entre los estados de carga y contenido listo mediante un botón.

los cuales son: 
- Cargando...
- Contenido Listo!

## Componentes
- App.tsx: pantalla principal.
- MainCard.tsx: componente que muestra el estado de carga.

## Comandos para ejecutar el proyecto

Instalar dependencias:

npm install

Iniciar el proyecto:

npx expo start
